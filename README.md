### Requirements

**1 Addon Required: Xperience**

This collection uses 100% TMDB lists via the Xperience addon.
You need to have Xperience installed and configured in Nuvio before importing.

- If you already use Xperience: it's a 1-click import.
- If you don't: install Xperience from `nuvio.tv/addons`, configure your TMDB API key, then import this collection.

**No other addons needed.**

### Installation (1-Click)

1. Install **Xperience** addon from Nuvio Addons page
2. Go to `nuvio.tv/account` -> `Collections` -> `Import Collections` (Use Overwrite mode if you already have Korean folders)
3. Paste this RAW link:
```
https://raw.githubusercontent.com/eichicionizuka82/nuvio_korean_collection/main/manifest.json
```
